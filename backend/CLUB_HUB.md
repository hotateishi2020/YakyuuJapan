# 球団情報・日程

## 更新

backend ディレクトリで実行します。DBへの書き込みはありません。

```sh
dart run tool_refresh_schedule.dart 2026
dart run tool_refresh_club_hub.dart 2026
```

首脳だけの再取得は `dart run tool_refresh_club_hub.dart 2026 --staff-only`。
公式発表の補足情報は `data/club-hub-sources-2026.json` に出典・公表時点とともに収録します。
取得結果は `data/schedule-2026.json` と `data/club-hub-npb-2026.json`、画像は `public/club-logos/2026/` です。デプロイ時にはこれらも同梱してください。

## 出典と収録範囲

- 日程: NPB公式の月別詳細日程、MLB Stats API。NPBのポストシーズンは試合詳細の大会名で公式戦から除外します。
- 監督・コーチ: NPB年度登録。抹消行は除外し、球団固有の役職名を保持します。
- オーナー・社長・特殊スタッフ・スカウト: 球団、親会社、関係自治体などの公式発表。公表日が異なるため画面で出典の日付を表示します。
- スポンサー: 球団公式スポンサー一覧と公式の広告契約発表。ロゴは公式画像を保存し、画像の確認ができない企業は社名を表示します。球場・ユニフォーム広告の区分は明記された契約のみ付与します。全広告主を網羅するものではありません。
- 自主トレ: 2026年シーズン前の公式発表で確認できた5グループ。参加者全体や全選手を網羅するものではありません。

首脳は12球団分の枠を表示します。未収録の役職は「未確認」で、役職自体の不存在を意味しません。現在、首脳・自主トレ・スポンサーの収録対象はNPBの2026年度です。MLBと他年度の未収録情報は空状態を表示します。

## APIと集計

`GET /club-hub?org=npb&year=2026` は公式情報スナップショットを返します。
`GET /season-schedule?org=npb&year=2026` は公式日程に既存DBの試合状態・確定スコアを反映します。ダブルヘッダーは開始時刻で照合し、識別できない行で2試合を上書きしません。

順位表の対戦成績と交流戦は終了した公式戦だけを数えます。交流戦の表示順位は勝率による参考順位で、同率を同順位とし、公式の同率決定規則は適用していません。

分析は取得済みシーズン成績から団体内の相対評価を計算します。打撃は打席加重OPS、走力は `(盗塁 - 2 × 盗塁死) / 打席`、守備は位置別UZR合計、先発・中継ぎは主な起用による投手群ごとの投球回加重WHIPです。投手の先発登板時・救援登板時それぞれのWHIPではありません。欠損値はゼロ評価にせず `—` にします。

レギュラーの年齢は守備位置ごとの最多起用野手を重複除外して算出し、生年月日が分かる人数も併記します。走塁データの追加列は次回の戦力データ更新後に利用可能になります。

日程・首脳スナップショットの定期実行は未設定です。更新コマンドを実行しない場合、新しい予定変更や人事は反映されません。DBに入る試合結果はAPI読取時に反映します。
