# 個人成績・選手詳細

## 表示

個人成績は従来の表と「グリッド表」を切り替えられます。グリッドは行が選手、列が指標で、見出しクリックで数値の昇順・降順を切り替えます。欠損値はどちらの順序でも末尾です。個人成績・試合の出場選手・戦力の選手一覧やレギュラー等から選手詳細を開きます。

- BB/9・四死球/9の個人成績・順位は規定投球回到達投手のみを対象にします。所属球団の当年試合数以上の投球回が必要で、投球回はアウト数で比較します。未到達・判定データ不足は対象外です。
- BB/9 = 四球 × 27 / アウト数。死球を含めません。
- 四死球/9 = (四球 + 死球) × 27 / アウト数。
- 平均投球回 = アウト数 / 3 / 全登板数。小数表記です。先発平均ではありません。
- 投球回数の `.1` / `.2` は1/3回・2/3回として計算します。
- ボール球見極め率 = 100 − Statcast O-Swing%。見逃しストライク率とは異なります。
- 代打打率 = 代打の安打 / 代打の打数。NPBは公式ボックススコアの代打起用時の最初の打席を集計し、その後の守備・打席を混ぜません。MLBは公式APIの `pH` 区分です。
- MLBの代打起用数は `pH` 区分の出場試合数。打席未完了の交代は含まれない場合があり、画面の注記で明示します。

## データ

2026年の追加指標・Statcast計測値・NPBの試合ログを同梱しています。NPBとMLBの公式データは項目の公開範囲が違います。未取得や計算不能はゼロにせず `—` / 未確認です。

出典:
- NPBの球団別打撃・投手・守備成績: https://npb.jp/bis/2026/stats/
- NPBの試合別ボックススコア: https://npb.jp/games/2026/schedule_03_detail.html
- MLB Stats APIの年度成績・代打区分・選手別試合ログ: https://statsapi.mlb.com/api/v1/
- Statcastのゾーン外スイング率・平均打球速度・一塁到達タイム: https://baseballsavant.mlb.com/leaderboard/custom
- 捕手Pop Time: https://baseballsavant.mlb.com/leaderboard/poptime
- 球種・平均球速: https://baseballsavant.mlb.com/leaderboard/pitch-arsenals
- BB/9定義: https://www.mlb.com/glossary/advanced-stats/walks-per-nine-innings

計測データは平均値・単位・出典を表示します。mphは1.609344倍してkm/hに換算します。Pop Timeは捕球から二塁到達までで、腕だけの送球動作時間ではありません。

趣味・特技・遠投、NPBのボール球見極め率や各種トラッキング値、ゾーン別打率は現時点で未収録です。出典付き補足は `data/player-profiles-YEAR.json` の選手ごとに `{value, source, as_of}` で追加できます。ゾーン別データを推測で生成する処理はありません。

選手のDB IDとNPB/MLB公式IDを区別します。名簿の名前または所属球団＋生年月日が一意に一致した場合だけ公式IDを結びます。同名で特定できない選手は誤った詳細を表示しません。実DBにある別IDの重複選手を勝手に統合することもありません。

NPBの直近25試合は公式ボックススコアとDBの終了試合を照合します。MLBは定期集計時に公式のレギュラーシーズン・ポストシーズン試合ログを補完します。取得失敗時は既存の確認済み記録を残します。25試合未満の選手は取得できた件数を表示します。

## ポストシーズンの調子

当該試合開始前の取得済み成績をシーズン成績と比較する参考評価です。PSの試合では取得済みのPS記録があればPSを使い、それ以外は直近25試合（PSを含む）を使います。シーズン基準値は現在取得している集計値です。実際の身体状態・精神状態を表すものではありません。

- 打者: 打率差 ±.040 / ±.100、10打数未満は少数サンプルの参考判定。
- 投手: 防御率の改善・悪化 ±0.75 / ±2.00、3回未満は少数サンプルの参考判定。
- 5段階の顔アイコン。打数・投球回がゼロ、または基準値なしは内部では判定保留とし、画面では黄色の普通顔を仮表示します。ツールチップに判定データ不足を明示します。
- 規定未到達選手は今季の経歴成績を参照します。試合用と成績用で選手IDが異なる場合は、同一球団かつ同一公式選手URLで照合します。
- 後日のPS試合や当該試合の結果を判定へ入れません。

## 更新・検証

backendディレクトリで順に実行します。詳細スナップショットと未登録ポジションはDBへ保存します。

```sh
dart run tool_refresh_player_metrics.dart 2026
dart run tool_refresh_pinch_metrics.dart 2026
dart run tool_refresh_mlb_positions.dart 2026
dart run tool_refresh_birthplaces.dart 2026
dart run tool_refresh_player_details.dart 2026
dart test test/player_detail_test.dart
```

サーバーは起動直後の取得を避け、6時間ごとに上記の公式データを順に更新します。既存の試合キャッシュは再利用します。`data/player-metrics-*`、`player-profiles-*`、`npb-pinch-games-*`、`npb-recent-games-*` を配布物に含めます。

## 詳細の事前集計

起動30秒後と6時間ごとに `t_player_detail_snapshot` を更新します。全選手に共通のプロフィール・シーズン成績・追加指標は1回だけ読み、選手ごとのJSONを `(int_year,id_player)` 主キーで保存します。ポップアップAPIは保存済みJSONを読むだけで、外部取得や成績集計を行いません。初回の未集計選手は準備中と表示します。更新失敗時は既存のスナップショットを残します。初回導入時は上記の詳細更新コマンドを先に完了させてください。

生成画像はポップアップに表示しません。直近25試合は1試合1行の表です。

出身地は確認済みの国・都道府県または州で表示し、未取得は未確認枠に残します。NPBの既存DBに出身地がない選手を学校所在地などから推測しません。

## MLB直近日程の再確認

`MlbScheduleWatch` はブラウザの起動に依存せず、日本時間の0時・6時・12時・18時に当日・翌日を再取得します。サーバー起動時は次の実行時刻を予約します。翌日分を前日に確認し、日付が変わっても当日分を確認し続けます。中止・延期や取得日程から消えた未実施試合は論理削除し、表示スナップショットとAPIキャッシュを更新します。未知HTML・通信失敗を「試合なし」と扱わず、終了・進行中・出場記録ありの試合を削除しません。

手動再確認: `dart run tool_recheck_mlb_schedule.dart`
確認のみ: `dart run tool_verify_mlb_schedule.dart`
