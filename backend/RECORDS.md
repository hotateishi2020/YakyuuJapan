# 記録データ

`GET /records?org=npb|mlb&year=2026` は読み取り専用です。順位・成績はDB、歴代記録・公式表彰・MLBの今季連続記録は `data/records.json` を読みます。応答は団体・年度別に10分間キャッシュします。Dockerイメージに同梱JSONを含めます。

更新は `backend` ディレクトリで実行します。DBへの書き込みはありません。

```sh
dart run tool_refresh_records.dart
dart run tool_refresh_record_awards.dart
dart run tool_refresh_record_streaks.dart 2026
```

同じJSONを更新するので、これらのコマンドは順番に実行してください。歴代記録の不足分だけを再取得する場合は最初のコマンドに `--missing` を付けます。再配置後に新しい同梱データが読み込まれます。記録ごとの確認日・出典は画面から参照できます。

- 歴代のシーズン・通算記録はNPB公式記録表とMLB Stats API。通算は上位10位まで（NPBは同順位を含む）。MLBは公式APIの歴史的リーグを含み、現代のAL/NLだけに限定していません。
- 個人タイトルは年度・リーグ単位。同率首位を保持し、公式表彰がある項目を優先します。NPBは1937年以降の年鑑のMVP・新人王、2006年以降の表彰ページ、MLBは公式のMVP・新人王・サイ・ヤング賞を収録します。公式表彰のない項目は登録済み成績の首位です。
- 順位は日次履歴の最新行を球団・年度ごとに選びます。シリーズの優勝は必要勝利数を満たした終了試合で判定します。MLBの1903・1919～1921年は5勝、それ以外は4勝です。ポストシーズン未登録年度の進出チームは推定しません。
- 連続記録は通常シーズンのみ。打席と打数、失点と自責点、連続登板と勝敗のついた登板を区別します。歴代記録は複数年度にまたがるものを含み、比較欄は選択年度内です。
- DB由来の連続記録は成績取得済みの連続区間だけを集計します。未取得試合で区切り、打席別集計にはボックススコアとの打席数一致を要求します。犠打・犠飛の区別がないボックススコアは連続安打を保守的に中断します。完全なシーズン最長とは表示しません。
- MLBの試合単位の比較値は全シーズン出場選手の公式gameLogを別途取得します。一部の選手の取得に失敗した場合は更新を失敗させ、部分的な母集団を首位として保存しません。連続出場は移籍前後を分けます。
- 打席単位のMLB今季記録、無失点投球回など、必要な詳細データがない場合は空値を明示します。MLB歴代連続ホールドは公式の最多記録が未確認です。手作業で検証した歴代連続記録は `streaks` に出典と確認日を添えて保存しています。
- 現役判定は公式の現役表示を優先し、判定できない選手は「現役区分未確認」と表示します。
