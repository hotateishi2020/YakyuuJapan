# 記録データ

`GET /records?org=npb|mlb&year=2026` は読み取り専用です。順位・成績はDB、歴代記録・公式表彰・今季連続記録は `data/records.json` を読み、表示用の `t_page_snapshot` に事前集計します。Dockerイメージに同梱JSONを含めます。

更新は `backend` ディレクトリで実行します。DBへの書き込みはありません。

```sh
dart run tool_refresh_records.dart
dart run tool_refresh_record_awards.dart
dart run tool_refresh_record_streaks.dart 2026
# NPBの年度内最長値（両リーグ）
python3 tool_refresh_npb_streaks.py 2026 --cache /tmp/npb-streaks-2026-20261026
# MLB全試合・全選手。途中再開時は同じcacheを指定。保存済み資料のみなら --offline。
python3 tool_refresh_mlb_streaks.py 2026 --cache /tmp/mlb-streaks-2026-20261026
```

新しい確認日の再調査には新しいキャッシュディレクトリを使います。通信失敗・年度違い・年間合計の不一致時はJSONを置き換えません。既存のDart版MLBコマンドも全項目監査のPython版を呼び出します。

確認後のDB反映は別操作です。以下は表示スナップショットの連続記録だけを更新し、更新前を指定ディレクトリへ保存してDBの読み戻し一致も検証します。

```sh
dart run tool_publish_record_streaks.dart 2026 /tmp/streaks-backup-20261026
```

本番の定期再集計にも修正を適用するには、更新したJSONとコードの配備が必要です。

球団記録タブの今季連続記録は、全国首位を球団へ振り分ける処理を廃止し、`club_current_streaks[年度].clubs` の球団別監査結果を使います。

```sh
python3 tool_refresh_club_streaks.py 2026 --cache /tmp/npb-club-streaks-2026-20261026
dart run tool_publish_club_streaks.dart 2026 /tmp/club-streaks-backup-20261026
```

12球団の公式年間成績から出場者を列挙し、NF3の全試合記録を年度内で再計算します。静的な選手ページの最高値とリーグ一覧表には一致しない箇所があるため、最高値の転記は採用しません。打者は出場・打席・安打・本塁打・四死球・盗塁・盗塁死、投手は登板・勝敗・セーブ・ホールド・失点・奪三振の年間合計をNPB公式と照合します。投手の打撃、途中退団選手、異体字、打撃結果の打点注記も扱います。連続出場は143試合の日程に並べて欠場で区切り、年間出場数の大小だけでは判定しません。

球団ごとの未確認項目は理由を表示し、全国首位や部分取得区間の値で補完しません。歴代欄は全国記録などの確認済み資料に限られ、球団史全体を網羅していないため「確認済みの歴代記録」と表示し、この比較だけでは球団新記録と判定しません。公開ツールは `club_records` の連続記録セルのみを更新し、他の記録を保持、更新前のバックアップと読み戻し一致検証を行います。

同じJSONを更新するので、これらのコマンドは順番に実行してください。歴代記録の不足分だけを再取得する場合は最初のコマンドに `--missing` を付けます。再配置後に新しい同梱データが読み込まれます。記録ごとの確認日・出典は画面から参照できます。

- 歴代のシーズン・通算記録はNPB公式記録表とMLB Stats API。通算は上位10位まで（NPBは同順位を含む）。MLBは公式APIの歴史的リーグを含み、現代のAL/NLだけに限定していません。
- 個人タイトルは年度・リーグ単位。同率首位を保持し、公式表彰がある項目を優先します。NPBは1937年以降の年鑑のMVP・新人王、2006年以降の表彰ページ、MLBは公式のMVP・新人王・サイ・ヤング賞を収録します。公式表彰のない項目は登録済み成績の首位です。
- 順位は日次履歴の最新行を球団・年度ごとに選びます。シリーズの優勝は必要勝利数を満たした終了試合で判定します。MLBの1903・1919～1921年は5勝、それ以外は4勝です。ポストシーズン未登録年度の進出チームは推定しません。
- 連続記録は通常シーズンのみ。打席と打数、失点と自責点、連続登板と勝敗のついた登板を区別します。歴代記録は複数年度にまたがるものを含み、比較欄は選択年度内です。
- DB由来の連続記録は成績取得済みの連続区間だけを集計します。未取得試合で区切り、打席別集計にはボックススコアとの打席数一致を要求します。犠打・犠飛の区別がないボックススコアは連続安打を保守的に中断します。完全なシーズン最長とは表示しません。
- 2026年NPBは15項目中12項目を照合。ヌルデータ置き場f3の「最高記録」列を両リーグで比較し、現在継続中の値と区別します。全試合出場はNPB公式の12球団全選手成績と143試合の球団日程で確認。盗塁は公式年間盗塁・盗塁刺と候補者19人の全試合合計を照合し、同日の成功・失敗の全順序を考慮して首位・同率が変わらないことを検証しています。
- 2026年MLBは15項目中14項目を照合。全1,472選手の公式gameLogと、中止を除く2,429試合のplayByPlayを集計。打席・安打・本塁打・四球・死球・盗塁・盗塁死・奪三振・投手の対戦打者数の年間合計は公式season成績と全選手で一致。連続出場は球団の最多試合数と同数出場した選手から上限を証明できる場合に限定します。証明できない年度は更新を失敗させます。
- 盗塁死プレーに伴って進塁した別走者を盗塁死に含めません。失策による生存でも公式に盗塁死が付く場合は中断します。２ストライク後の代打が三振した打席は元打者に帰属。打席途中の投手交代で有利なカウントを引き継いだ四球は前任投手に帰属。走者のアウト、安打後の走塁死を打者の連続凡退と混同しません。打席のない中止時の告知を打席に数えません。
- 未確認のNPB3項目（連続無失点投球回・連続アウト・連続奪三振）とMLB1項目（連続無失点投球回）は `categories.status=unavailable` とし、部分取得したDBの値で補完しません。年度内最長が未確認である理由を画面に表示します。個別の達成報道だけで年間首位とは判定しません。
- 監査結果は `current_streaks[年度].categories` に確認状態・出典・説明、スナップショットに確認日時と取得資料のSHA-256を保持します。MLB歴代連続ホールドは公式の最多記録が未確認です。歴代欄は今回の今季監査とは別です。
- 現役判定は公式の現役表示を優先し、判定できない選手は「現役区分未確認」と表示します。

### 過去のレギュラー・投手エースの補完

`tool_enrich_regular_history.py` は2005年以降のNPB公式球団別成績を取得し、
`tool_enrich_regular_archive.py` は1981年以降の年度別資料（ウスコイ企画）と
選手プロフィールから不足成績・投球左右・先発登板数を補完する。
両ツールは `beautifulsoup4` が必要。取得資料は `/tmp/koko-regular-*` にキャッシュする。
公式データがある選手は登板・投球回・セーブ・ホールドを照合し、不一致の年度は更新しない。
出典URLは各年度の `official_stat_sources` / `archive_stat_sources` と各投手に保存する。

ポジション表示の汎用「投手」列は使用しない。投手は左右別先発・左右別救援・守護神で表示。
先発・救援の実投球回が確定できない過去年は、先発登板数で先発を、ホールド→救援登板数で
救援を選出する。投球回の配分は推測せず、先発回数または救援登板数を表示する。
ホールド制度以前の未記録値は0ホールドとして表示しない。
取得後は `test/regular_history_identity_test.dart` と `test/regular_history_loader_test.dart`、
`backend/test/regular_history_enrichment_test.py` を確認する。

`dart backend/tool_audit_regular_history.dart`（リポジトリルートから実行）で全年度の
投球左右・先発登板数と選出漏れを検証し、`data/regular-history-audit.json` に出典と結果を保存する。
2026-10-26の監査対象は1981〜2025年の540球団年度。左先発の登板がない
1996年日本ハム・1981年南海・1981年広島のみ、左先発欄を「該当なし」とする。
