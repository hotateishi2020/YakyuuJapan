# ドラフト・エラー画面

## ドラフト資料の更新

backend ディレクトリで `dart run tool/import_draft_history.dart 2025` を実行します。
1965年〜指定年の公開資料を `.dart_tool/draft-source/` にキャッシュし、
`assets/data/draft_history.json` を生成します。未開催年は指定しないでください。
更新後は Flutter Web を再ビルドします。各年度の出典URLを画面に掲載しています。
全指名には育成・自由獲得枠・希望入団枠を含み、1966年は第1回と第2回を区別します。
1位一覧は通常指名の1位を対象とし、自由獲得枠等は球団別全指名で確認できます。
1978年の巨人は不参加のため指名データがありません。

## エラー画像

Flutter/プラットフォームの未処理エラーと共通通信エラー処理で、アプリの直前に描画済みのフレームをPNGとして送信します。
管理者ログの行を開くと画像を確認できます。ブラウザのアドレスバーや外部のHTML埋め込みは含まれません。
描画自体が壊れた場合など、画像取得に失敗してもエラー本文は記録します。
PNGは最大1.5MB・長辺1280px。`ERROR_SNAPSHOT_DIR`（既定 `var/error-snapshots`）に保存します。
公開ディレクトリ外の永続ボリュームを指定してください。1000件に達した場合、新しい画像は保存せず本文のみ記録します。
管理者向け `/admin/logs/snapshot/:id` だけが画像を配信します。画像取得に認証が必要で、ブラウザキャッシュは無効です。
