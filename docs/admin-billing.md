# 管理者画面の費用

管理者画面の「費用」で、NeonとRenderの月次金額を登録・表示できます。

- 未確定利用額：選択月の利用について、各社の管理画面で確認した時点の金額。
- 確定額：選択月に発行された請求書の金額の合計。利用対象期間は発行月と異なる場合があります。
- 通貨はUSDまたはJPY。USDは整数セント、JPYは整数円で保存します。
- 両指標は合算しません。未登録と0は別表示です。
- 利用対象期間と手動確認日時を表示します。確認日時は保存時刻です。
- 各月・サービス・金額の種類ごとに最新の確認値を保存し、過去月も閲覧・更新できます。

現状は手動登録です。Neon/Renderからの自動取得や請求書の自動取り込みは実装していません。APIキーをブラウザーに入力する機能もありません。

`GET /admin/billing?month=YYYY-MM` と `POST /admin/billing` は、既存のログインセッションと管理者フラグで認可します。一般ユーザーや未認証では閲覧・保存できません。レスポンスは `Cache-Control: no-store`。

保存先は `t_admin_billing`。初回アクセス時に作成されます。事前準備する場合はbackendディレクトリから `dart run tool_setup_admin_billing.dart` を実行してください。
